1 Get going

git clone https://github.com/GoncaloLeitao/workers-caff-hackathon.git
cd workers-caff-hackathon
npm install
npx wrangler login
npm run deploy

You need a free Cloudflare account, Node.js 22+ and Git. New accounts pick a workers.dev subdomain on the first deploy: any name works.

No Node here? Use Deploy to Cloudflare in the README, then GitHub's web editor (press . on your repo). Each commit redeploys.

3 The code you'll write

// src/mcp.ts: every tool has the same shape. get_menu is done for you: copy its pattern.
server.registerTool(
  "get_menu",                                       // the name the model calls
  {
    description: "List everything on the menu: ...", // how the model decides when to use it
    inputSchema: z.object({}),                      // a zod schema: what the model must send
    annotations: { readOnlyHint: true }             // a hint that it changes nothing
  },
  async () => asText(await caff.getMenu())          // do the work, send back JSON text
);

// What caff can do. Prices are in pence, tables are 1 to 12, orders only move forward.
caff.getMenu()                         caff.placeOrder({ table, items: [{ itemId, qty }], note })
caff.listOrders({ status, table })     caff.updateOrderStatus(orderId, "cooking" | "ready" | "served" | "cancelled")
caff.restockItem(itemId, quantity)     caff.requestRefund(orderId, reason)     caff.checkApproval(approvalId)

// src/agent.ts, TODO 1: connect Sid to your MCP server
await this.addMcpServer("caff", `${origin}/mcp`, {
  transport: { type: "streamable-http", headers: { "x-caff-client": "agent", "x-caff-origin": origin } }
});

// TODO 2, inside generateText({ ... }): give the model every tool your MCP server offers
tools: this.mcp.getAITools(),

caff throws readable errors (sold out, unknown item). The MCP SDK passes them to the model as tool errors, so you can skip the try/catch.

npm run skip:mcp · skip:agent · skip:all · skip:stretchDrop in a finished version. Yours is saved as src/*.ts.bak

5 If it breaks

Sid says he isn't connectedFinish both TODOs in src/agent.ts and deploy again
New tools missing in AI PlaygroundCustom MCP → Tools → Refresh
"Couldn't use your MCP server"Something in src/mcp.ts throws, often a tool registered twice. npm run smoke -- <url> shows the error
Error 1042Keep global_fetch_strictly_public in wrangler.jsonc: Sid needs it to call your Worker's public URL
Free Workers AI allowance used upSet vars.MODEL to "@cf/zai-org/glm-4.7-flash" in wrangler.jsonc and deploy
